# EcoData Reliability Hub

A progressive Data Engineering project for monitoring the quality,
reliability and traceability of environmental data.

## Project purpose

Environmental decisions depend on reliable data. Measurements from
sensors, spreadsheets and APIs may contain missing values, duplicates,
incorrect units, impossible values or outdated timestamps.

EcoData Reliability Hub will ingest environmental data, validate its
quality, record detected issues and produce explainable quality reports.

## Current status

The first version uses a small CSV dataset containing valid and
intentionally invalid environmental measurements.

All sample records are clearly labelled as simulated data.

## Planned development
